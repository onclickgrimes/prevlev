# Cobertura dos 40 recursos

Implementação independente; não há declaração de paridade completa com Nexlev 3.12.6.

“Implementado” significa disponível no escopo descrito. Esse estado não declara paridade nem teste com extensão instalada. Dados faltantes não são preenchidos com resultados fictícios.

## O que foi verificado

- Testes unitários/DOM e integração em loopback verificam partes do comportamento usando fixtures. Os testes de adaptador de IA simulam o provedor somente no teste.
- Quatro testes de UI passaram no Chromium com APIs Chrome fornecidas por fixture. Dois em [ui.spec.ts](../tests/browser/ui.spec.ts) cobrem coleta, filtros, salvar/exportar Swipe File, estado de IA não configurada e canvas real para compressão/prévia. Dois em [studio-ui.spec.ts](../tests/browser/studio-ui.spec.ts) integram os bundles próprios `workspace.js`/`content.js` através de transporte Chrome simulado para prévia, confirmação, cancelamento e recusa de alvo alterado. Nos testes Studio todas as URLs são interceptadas, sem conta real ou contato com YouTube. Isso não é execução de extensão instalada.
- Os dois testes de extensão instalada em [tests/browser/extension.spec.ts](../tests/browser/extension.spec.ts) foram explicitamente ignorados: a política gerenciada `/etc/chromium` contém `ExtensionInstallBlocklist=[*]`. Nenhuma tentativa de contorno foi feita. **Ignorado não significa aprovado.**
- Não houve operação em conta/canal real do YouTube/Studio, teste de todos os layouts atuais ou chamada real a provedor de IA.

## Pendências materiais

- Pesquisa global e enriquecimento abrangente de canais exigem escolher e implementar uma fonte de dados autorizada; o backend atual trabalha com a amostra fornecida. O enriquecimento público de inscritos é manual e limitado.
- Receita, RPM, geografia, contratos de patrocínio e saturação global não são inferidos dos dados públicos disponíveis.
- IA exige um servidor/provedor configurado pelo operador. Credenciais de provedores não pertencem à extensão.
- Seletores do Studio podem mudar. Mid-roll não cria ou salva intervalos; monetização usa apenas escolha já feita pelo usuário.
- Sincronização de Swipe File, MCP e autenticação multiusuário não estão implementados.
- A integração de uma extensão instalada deve ser verificada em ambiente autorizado que permita extensões. A política deste ambiente não foi alterada.
